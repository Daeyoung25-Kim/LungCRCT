# LungCRCT
LungCRCT source code

## What is LungCRCT?

LungCRCT is a causal representation learning based Lung CT processing framework that can expand current deep learning applications in clinical areas from detection or classification tasks to visual intervention analysis or treatment simulations.
Finding representations that can correspond with physical causal factors of lung cancer, such as tumor, angiogenesis, or lymph node enlargements, from CT images with weak supervision, LungCRCT succeeds in both extracting valid latent causal space regarding lung cancer progression and constructing competitive downstream models (malignant/non-malignant lung CT classification) with extremely less parameters, when compared to existing transfer learning-based deep computer vision models.
